# Ana Monalisa Boutique

Site vitrine para uma boutique de moda feminina, desenvolvido com o objetivo de apresentar a marca e seus produtos e facilitar o contato com os clientes pelo WhatsApp.

## Objetivos

- Apresentar a boutique e sua identidade visual.
- Exibir um catálogo de produtos.
- Facilitar o contato dos clientes com a loja pelo WhatsApp.
- Construir uma base que possa evoluir futuramente para uma loja virtual completa.

## Tecnologias

- HTML5
- CSS3
- Git e GitHub
